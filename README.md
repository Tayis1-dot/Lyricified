# 🎵 Lyricified

A modern application for managing, discovering, and enjoying lyrics with style.

## Features

- 🎶 Browse and search song lyrics
- ⭐ Save favorite lyrics and playlists
- 🎨 Beautiful UI for lyrics display
- 🔍 Advanced search capabilities
- 📱 Responsive design

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Tayis1-dot/Lyricified.git

# Navigate to project directory
cd Lyricified

# Install dependencies
npm install

# Start the development server
npm run dev
```

### Build for Production

```bash
npm run build
npm start
```
